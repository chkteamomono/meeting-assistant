📁 회의 기록 저장 위치

녹취록·회의록·안건판이 저장되는 폴더입니다. 비워두면 기본 위치(앱 폴더 아래 "03. 회의 기록")를 씁니다.
현재 적용 중: 확인 중…
폴더가 없으면 자동으로 만듭니다. 외장 드라이브처럼 연결이 끊길 수 있는 위치를 지정하면, 연결이 끊긴 동안은 자동으로 기본 위치에 저장됩니다.

🪄 보정 작업

실시간 받아쓰기는 속도가 우선이라 10초씩 끊어서 처리해 문장 경계에서 오탈자가 잘 생깁니다. 이 기능을 켜면 같은 녹음을 60초 단위로 더 크게 묶어 별도 스레드에서 다시 한번 받아써서 오탈자를 줄인 "보정본"을 만듭니다. 화면의 실시간 자막에는 반영되지 않고(끊겨 보이는 걸 막기 위함), 회의가 끝나면 이 보정본으로 회의록을 작성하고 별도 파일로도 저장합니다. 회의 중 원본 음성 파일도 함께 저장됩니다.
보정 작업 사용
실시간 받아쓰기와 동시에 두 번째 받아쓰기가 돌아가는 것이라 CPU를 더 씁니다 — 컴퓨터가 느려지거나 실시간 자막이 자주 밀리면 꺼두세요(꺼도 실시간 받아쓰기·회의록 작성 자체는 그대로 됩니다. 다만 회의록은 실시간본 기준으로 작성됩니다).

🗂️ 노션 연동

회의가 끝나고 회의록이 만들어지면, 지정한 노션 페이지에 그 내용을 그대로 이어서 작성합니다. 둘 다 입력해야 작동합니다.
회의록을 이어붙일 노션 페이지를 열어서 주소창의 URL을 그대로 복사해 붙여넣으세요.
처음 연동하는 경우 — 준비 방법
  1. 노션에서 notion.so/my-integrations 페이지로 이동해 "새 통합 만들기"로 통합을 하나 만드세요.
  2. 만들어진 통합의 "내부 통합 비밀번호(Secret)"를 복사해 위 "노션 API 키"에 붙여넣으세요.
  3. 회의록을 받을 노션 페이지를 열고, 우측 상단 "···" 메뉴 → "연결 추가"에서 방금 만든 통합을 선택해 이 페이지에 연결하세요. (이 단계를 빼먹으면 API 키가 맞아도 "페이지를 찾을 수 없습니다" 오류가 납니다.)
  4. 그 페이지 주소를 위 "노션 페이지 주소"에 붙여넣고 저장 → "연결 테스트"로 확인하세요.

⏻ 프로그램 종료

이제 창을 띄우지 않고 실행되기 때문에, 끌 때는 여기서 끕니다. (안 눌러도 컴퓨터를 끄면 함께 종료됩니다)
