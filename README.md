# 회의 보조 비서

회의를 실시간으로 받아쓰고, 안건별 진행 상황을 자동으로 정리하고, 회의가 끝나면 공유용
회의록을 만들어주는 로컬 웹앱입니다. 같은 PC에서만 접속되고(localhost), 음성은 PC 밖으로
나가지 않습니다.

## 무엇을 하는가

1. **안건을 먼저 적어둔다** — 회의 시작 전이든 진행 중이든 언제든 추가·수정·삭제 가능
2. **회의 중 실시간 받아쓰기** — 마이크 소리를 텍스트로 계속 저장, 화면에 자막처럼 표시
3. **안건별 진행 상황이 실시간으로 채워진다** — 25~30초마다 지금까지 나온 이야기를 안건과
   연결해 논의 요약·결정 사항·액션 아이템을 자동으로 채움. 목록에 없던 주제가 뚜렷하게
   나오면 새 카드가 자동으로 추가됨
4. **회의 종료 시 회의록 자동 생성** — 받아쓰기 전문 + 마지막 안건 상태를 바탕으로 공유용
   회의록(.md)을 만들어 저장

핵심 원칙: **안건 제목은 항상 사람이 소유**합니다. AI는 진행 상황(요약·결정·액션 아이템)만
채우고, 제목을 만들거나 바꾸지 않습니다 — 회의를 대신 진행하거나 결론을 내리지 않고, 오간
내용을 사람이 정한 안건 틀 안에 구조화해서 보여주는 역할만 합니다.

## 구조 — 두 개의 받아쓰기 파이프라인

| | 실시간 | 보정 작업 |
|---|---|---|
| 목적 | 빠르게 화면에 보여주기 | 나중에 정확하게 |
| 처리 단위 | 10초씩 | 60초씩(더 넓은 문맥) |
| 결과 | 화면 자막, 안건판 갱신 | 별도 파일로 저장, 회의록 작성에 우선 사용 |
| 동시 실행 | 항상 켜짐 | 설정에서 켜고 끌 수 있음(CPU 더 씀) |

회의 중 마이크 원본은 16kHz 모노 WAV로도 저장되어, 보정 작업이 이 녹음을 바탕으로 다시
받아씁니다.

```
회의 보조 에이전트/
├── 01. 페르소나설정/          기획 의도·시스템 프롬프트 문서
├── 02. 회의 보조 비서 실행하기/   ← 실제 프로그램
│   ├── 서버.py                Flask 백엔드 (오디오/STT/보정/안건판/회의록/노션)
│   ├── index.html             메인 화면
│   ├── settings.html          설정 화면
│   ├── 1_설치하기.bat / 2_실행하기.bat / 3_종료하기.bat
│   └── requirements.txt
├── 03. 회의 기록/              회의별 결과물 (실행 중 자동 생성, 저장소에는 비포함)
└── 참고자료/
    ├── 받아쓰기_용어.txt       받아쓰기 정확도를 높이는 고유명사 힌트 (직접 채워 쓰는 파일)
    └── 회의록_형식.txt         회의록 작성 규칙(마크다운 템플릿, 비워두면 내장 기본값)
```

## 필요한 것

- Windows, Python 3.11 이상
- **Claude Code CLI** (`claude` 명령어) — 이 PC에 설치·로그인되어 있어야 안건판 자동 정리와
  회의록 생성이 동작합니다. 없어도 실시간 받아쓰기 자체는 되지만, 그 이후 단계는 못 씁니다.
- 마이크

## 시작하는 법

1. `02. 회의 보조 비서 실행하기` 폴더의 **`1_설치하기.bat`** 더블클릭 (최초 1회, 필요한
   패키지를 설치합니다)
2. **`2_실행하기.bat`** 더블클릭 — 검은 콘솔 창 없이, 잠시 후 브라우저가 자동으로 열립니다
   (안 열리면 `http://127.0.0.1:8001` 접속)
3. 회의 기업/주제를 적고(선택) 안건을 미리 적어둔 뒤 **▶ 회의 시작**
4. 회의가 끝나면 **⏹ 회의 종료** — 1~2분 뒤 회의록이 만들어집니다

**끌 때**는 따로 안 눌러도 됩니다 — 탭을 닫으면 진행 중인 작업(회의·회의록 작성)이 끝나는
대로 자동 종료됩니다. 바로 끄고 싶으면 설정(⚙️)의 "서버 종료" 버튼이나 `3_종료하기.bat`.

## 설정 (⚙️ 설정 화면)

- **저장 위치** — 회의 기록이 쌓일 폴더를 바꿀 수 있습니다 (기본값: 앱 폴더 아래
  `03. 회의 기록`)
- **보정 작업** — 켜고 끌 수 있습니다 (기본 켜짐)
- **노션 연동** — 두 가지 방식
  1. **API 자동 업로드**: 노션 페이지 주소 + API 키를 등록하면 회의록이 완성될 때 그 페이지에
     자동으로 이어붙습니다. 워크스페이스 관리자 승인(연결/통합 생성 권한)이 필요할 수 있습니다.
  2. **복사용 자료 생성**: API 키 없이도, 회의록이 완성되면 뜨는 "노션 업로드용 자료 생성"
     버튼으로 마크다운 전문을 팝업에서 바로 복사해 노션에 붙여넣을 수 있습니다.

## 참고자료 파일 채우는 법

- `참고자료/받아쓰기_용어.txt`: 회의에서 자주 나오는 고유명사(회사명·사업명·기관명 등)를
  한 줄에 하나씩 적어두면 받아쓰기 정확도가 올라갑니다. 너무 많이 넣으면 오히려 인식이
  나빠지니(실측상 20개 안쪽 권장) 자주 쓰는 것부터 위에 적으세요. 파일이 없어도 동작합니다.
- `참고자료/회의록_형식.txt`: 팀 고유의 회의록 양식이 있으면 이 파일에 적어두세요. 비워두면
  프로그램에 내장된 기본 형식을 씁니다.

## 알아두면 좋은 것

- 음성 인식은 로컬에서 도는 faster-whisper 모델을 씁니다 — 음성 자체가 외부로 나가지
  않습니다(노션 API를 연동한 경우, 완성된 텍스트 회의록만 노션으로 전송됩니다).
- 마이크는 Windows WASAPI 경로를 우선 사용해 품질을 높입니다. 다른 프로그램이 마이크를
  점유해 실패하면 자동으로 재시도하고, 계속 실패하면 시스템 기본 장치로 폴백합니다(화면에
  배너로 안내).
- `03. 회의 기록` 폴더(실제 회의 녹음·녹취록·회의록)는 이 저장소에 포함되지 않습니다 —
  각자 PC에 로컬로만 쌓입니다.
