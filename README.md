# 기록 보조 비서

회의 보조 비서와 면접 보조 비서를 하나의 런처에서 골라 쓰는 통합 도구입니다. 둘 다 로컬
웹앱으로 동작하고, 같은 PC에서만 접속되며(localhost), 음성은 PC 밖으로 나가지 않습니다.

## 시작하는 법

1. **`실행하기.bat`**(최상단) 더블클릭 — 그게 전부입니다. 필요한 패키지가 없으면 자동으로
   설치까지 하고(최초 1회, 몇 분 걸릴 수 있음) 바로 이어서 켭니다. 검은 콘솔 창 없이, 잠시
   후 브라우저에 "오늘은 어떤 작업을 할까요?" 화면이 뜹니다 (안 열리면
   `http://127.0.0.1:7999` 접속)
   - 이때 회의·면접 데이터 폴더가 하나도 없으면(클론 직후 등) 아래 "구조"에 나온
     기본 폴더트리(빈 템플릿)를 자동으로 만들어줍니다. 이미 폴더가 있으면 손대지
     않습니다 — 기존 운영 데이터를 건드리는 일은 없습니다.
2. **[면접진행]** 또는 **[회의진행]** 클릭 → 해당 비서를 자동으로 켜고 그 화면으로
   이동합니다 (처음 켤 때는 whisper 모델 로딩 때문에 1분 가까이 걸릴 수 있음)
3. 각 화면에서 **🏠 처음으로**를 누르면 언제든 이 런처로 돌아올 수 있습니다

두 비서 중 하나만 개별로 켜고 싶다면 `소스코드/02. 회의 보조 비서 실행하기` 또는
`소스코드/02. 면접 보조 비서 실행하기` 폴더의 `2_실행하기.bat`를 직접 실행해도 됩니다 —
런처는 이미 켜져 있는 쪽을 감지하면 새로 띄우지 않고 그대로 이동만 시킵니다.

**끌 때**는 회의·면접 비서는 따로 안 눌러도 됩니다 — 탭을 닫으면 진행 중인 작업이 끝나는
대로 자동 종료됩니다(각 화면의 ⚙️ 설정에서 바로 끄는 것도 가능). 런처는 계속 떠 있는 게
정상이라 자동 종료되지 않고, 끄려면 `소스코드/00. 시작하기/3_종료하기.bat`를 씁니다.

`실행하기.ico`는 `실행하기.bat`용 아이콘입니다. `.bat` 파일 자체엔 아이콘을 못 입히므로
(Windows 자체 제약), 바로가기를 만들어 대상으로 `실행하기.bat`를, 아이콘으로 이 파일을
지정하면 바탕화면 등에서 예쁜 아이콘으로 쓸 수 있습니다.

## 구조

실제로 누르는 진입점(`실행하기.bat`)만 최상단에 바로 보이게 두고, 나머지 코드(소스코드/)와
데이터(이름에 "회의관리"·"면접"이 들어간 폴더)는 분리했습니다 — 저장소에는 `실행하기.bat`와
`소스코드/`(코드)만 올라가고, 회의·면접 관련 실제 내용은 전부 로컬에만 남습니다(아래 "공개
범위" 참고).

```
기록 보조 비서/
├── 실행하기.bat                      ← 이거 하나만 누르면 됨 (설치 확인 → 런처 실행)
├── 소스코드/                         ← 코드 전부 (저장소에 공개)
│   ├── 00. 시작하기/                  런처: "오늘은 어떤 작업을 할까요?"
│   ├── 02. 회의 보조 비서 실행하기/   회의 프로그램 (포트 8001)
│   └── 02. 면접 보조 비서 실행하기/   면접 프로그램 (포트 8000)
├── (이름에 "회의관리"가 들어간 폴더)/  ← 회의 관련 데이터 전부 (저장소엔 비포함)
│   ├── 01. 페르소나설정/
│   ├── (이름에 "회의 기록"이 들어간 폴더)/  실제 회의 녹음·녹취록·회의록
│   ├── 참고자료/                     받아쓰기 고유명사 / 회의록 형식
│   └── 설정.json                     노션 API 키 등
└── (이름에 "면접"이 들어간 폴더)/      ← 면접 관련 데이터 전부 (저장소엔 비포함)
    ├── 01. 페르소나설정/             회사명·채용기준 등 실제 운영 내용
    ├── (이름에 "면접자"·"면접로그"가 들어간 폴더)/  지원자 이력서·PII
    └── 참고자료/                     직무정보·질문뱅크
```

이 두 데이터 폴더는 번호를 붙이거나 이름을 바꾸는 일이 잦습니다(예: `회의관리` →
`2. 회의관리`). 코드(`find_root`)와 `.gitignore` 둘 다 정확한 이름이 아니라 **이름에 저
낱말이 들어가는지**로 찾으므로, 앞에 번호를 붙이거나 뒤에 말을 덧붙이는 정도는 자유롭게
바꿔도 됩니다 — 다만 "회의관리"·"면접"이라는 낱말 자체를 완전히 다른 말로 바꾸면 코드와
`.gitignore`를 둘 다 함께 고쳐야 합니다(안 그러면 비공개 처리가 깨집니다).

## 회의 보조 비서

1. **안건을 먼저 적어둔다** — 회의 시작 전이든 진행 중이든 언제든 추가·수정·삭제 가능
2. **회의 중 실시간 받아쓰기** — 마이크 소리를 텍스트로 계속 저장, 화면에 자막처럼 표시
3. **안건별 진행 상황이 실시간으로 채워진다** — 25~30초마다 지금까지 나온 이야기를 안건과
   연결해 논의 요약·결정 사항·액션 아이템을 자동으로 채움. 목록에 없던 주제가 뚜렷하게
   나오면 새 카드가 자동으로 추가됨
4. **회의 종료 시 회의록 자동 생성** — 받아쓰기 전문 + 마지막 안건 상태를 바탕으로 공유용
   회의록(.md)을 만들어 저장

핵심 원칙: **안건 제목은 항상 사람이 소유**합니다. AI는 진행 상황(요약·결정·액션 아이템)만
채우고, 제목을 만들거나 바꾸지 않습니다.

받아쓰기는 두 파이프라인으로 돈다: 실시간(10초 단위, 화면 자막용)과 보정 작업(60초 단위,
더 넓은 문맥으로 다시 받아써서 회의록에 우선 사용 — 설정에서 켜고 끌 수 있음, 기본 켜짐).

설정(⚙️) 화면에서 회의 기록 저장 위치, 보정 작업 on/off, 노션 연동(API 자동 업로드 또는
복사용 자료 생성 팝업)을 관리합니다.

## 면접 보조 비서

지원자 이력서를 미리 읽고 맞춤 질문을 준비해두고, 면접 중 실시간 받아쓰기로 답변을 판정해
추가로 물어볼 것(🟡)과 물으면 안 되는 것(🔴, 차별 소지 질문)을 알려줍니다. 면접이 끝나면
공유용 요약과 노션 붙여넣기용 정리본을 만들어줍니다.

회사 고유의 채용 기준·직무 정보·실제 질문 뱅크·지원자 개인정보를 다루기 때문에, 이 도구를
다른 조직에서 쓰려면 면접 데이터 폴더 안의 `01. 페르소나설정/`과 `참고자료/`를 각자 상황에
맞게 새로 채워야 합니다(아래 "공개 범위" 참고).

## 필요한 것

- Windows, Python 3.11 이상
- **Claude Code CLI** (`claude` 명령어) — 없어도 두 비서 모두 실시간 받아쓰기·녹취록
  저장은 됩니다. 다만 **회의 안건판 자동 정리·회의록 생성**, **면접 실시간 판정·맞춤
  질문·면접 요약**은 이게 있어야만 동작합니다. VS Code나 Antigravity 같은 특정 에디터
  전용이 아니라, 이 PC에 독립적으로 설치·로그인해두면 되는 별도 프로그램입니다. 없다면
  `claude --version`으로 설치 여부를 먼저 확인하세요.
- 마이크

## 공개 범위 (중요)

이 저장소는 **Public**입니다. `소스코드/`(코드)만 공개하고, 회의·면접 데이터 폴더(실제 운영
데이터·개인정보)는 폴더째 `.gitignore`로 저장소에서 제외합니다 — 회의 녹음·녹취록·회의록,
지원자 이력서·이름·면접 대화록(PII), 회사명·채용 기준·면접 질문 뱅크가 담긴 페르소나·참고
자료, 노션 API 키(`설정.json`) 전부 포함됩니다. `.gitignore`는 정확한 폴더명이 아니라
이름에 "회의관리"·"면접"이 들어가는지로 판단하므로(위 "구조" 참고), 번호를 붙이는 정도의
개명은 자동으로 계속 안전하게 걸립니다.

새로 이 도구를 쓰려면(또는 클론 직후) 회의·면접 데이터 폴더 안의 페르소나·참고자료 파일을
각자 상황에 맞게 직접 채워야 합니다 — 파일이 없어도 프로그램은 기본값으로 동작합니다.

## 참고자료 파일 채우는 법 (회의)

- 회의 데이터 폴더의 `참고자료/받아쓰기_용어.txt`: 회의에서 자주 나오는 고유명사(회사명·
  사업명·기관명 등)를 한 줄에 하나씩 적어두면 받아쓰기 정확도가 올라갑니다. 너무 많이
  넣으면 오히려 인식이 나빠지니(실측상 20개 안쪽 권장) 자주 쓰는 것부터 위에 적으세요.
- 회의 데이터 폴더의 `참고자료/회의록_형식.txt`: 팀 고유의 회의록 양식이 있으면 이 파일에
  적어두세요. 비워두면 프로그램에 내장된 기본 형식을 씁니다.

## 알아두면 좋은 것

- 음성 인식은 로컬에서 도는 faster-whisper 모델을 씁니다 — 음성 자체가 외부로 나가지
  않습니다(노션 API를 연동한 경우, 완성된 텍스트만 노션으로 전송됩니다).
- 마이크는 Windows WASAPI 경로를 우선 사용해 품질을 높입니다. 다른 프로그램이 마이크를
  점유해 실패하면 자동으로 재시도하고, 계속 실패하면 시스템 기본 장치로 폴백합니다.
- 회의·면접 데이터 폴더 등 실제 운영 내용이 담긴 폴더는 이 저장소에 포함되지 않습니다 —
  각자 PC에 로컬로만 쌓입니다.
